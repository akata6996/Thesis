How to Verify (Non-Technical Guide)

  1. Download the Verified Dataset and Merkle Verification Script from the Downloads page.
  2. Run the Python script with the dataset file path as instructed in the script README.
  3. Copy the Merkle root output generated by the script.
  4. Open the corresponding Solana Transaction ID from the Blockchain Anchors page.
  5. Compare the script output hash with the anchored Merkle root in Solana Explorer.

If the values match, the anchored dataset can be verified as unchanged since anchoring.
